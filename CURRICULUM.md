# Applied Machine Learning

## Published scope

Official module link: https://www.comp.nus.edu.sg/executive-education/course/sctp-applied-machine-learning/

Published classroom days: 2. The week below is an original expanded self-study schedule, not the official timetable.

## Learning outcomes
- Build regression and classification baselines
- Separate training, validation and final testing
- Measure precision, recall, error and threshold tradeoffs

## Five-day learning plan
- Day 1: problem framing and split strategy (2h)
- Day 2: regression and gradient descent (3h)
- Day 3: logistic classification and thresholds (3h)
- Day 4: complexity, validation and leakage (2h)
- Day 5: error analysis and model card (4h)

## Project
A held-out synthetic intervention classifier with a model card

## Boundaries
Student metrics are not treated as independently reproduced. The core uses transparent NumPy implementations; scikit-learn comparison is an extension.

## Completion evidence
- Clean notebook execution and changed-control screenshots
- Exercise code and deterministic tests
- Lab log with at least two failures
- Dataset/model card where appropriate
- Assessment answers before reading the solutions
